# Vico chips de lentilles : étude de prix et format familial

Projet étudiant. Site : https://linasouilmi.github.io/vico-chips-lentilles/

**Problématique** : Vico doit-elle lancer un format familial de ses chips aux lentilles de 200 g à 4,99 €, au lieu du sachet de 85 g vendu 2,69 €, et combien de sachets ou de formats familiaux doit-elle vendre pour que cette nouvelle offre soit rentable ?

## Contenu

| Page | Contenu |
|---|---|
| `index.html` | Problématique, chiffres clés, démarche |
| `concurrents.html` | Prix au kilo de Vico et de ses concurrents (directs, indirects, substituts) |
| `carte.html` | Carte de France des prix (7 villes) |
| `enseignes.html` | Comparaison Carrefour, Auchan, E.Leclerc, Intermarché |
| `format-familial.html` | Petit format contre grand format chez les concurrents, prix cohérent pour 200 g |
| `rentabilite.html` | Simulateur de seuil de rentabilité |
| `methodologie.html` | Sources, magasins, limites |

## Données

`assets/donnees.js` : prix relevés le 01/10/2026 sur les sites drive des enseignes (un magasin par enseigne et par ville). Le fichier Excel complet est dans `donnees/`.
